      Set up (one time)
      1. In Google Cloud → Credentials, create an OAuth client ID of type Web application.
      2. Under Authorised JavaScript origins, add this page's address.
      3. Turn on the Google Drive API for the project.
      4. Paste the client ID here. It's kept in this browser only.

      This page is open straight from a file. Google sign-in only works from a web address: run python3 -m http.server 4610 in the nn folder and open http://localhost:4610.
