      Import from Acuity

      1. In Acuity, open Reports → Export and download the appointments CSV.
      2. For everyone on Acuity's client list too, open Clients → Export (Import/Export) and download that CSV as well.
      3. Choose a file below (or paste what's in it) and press Import. One file at a time; importing the same file again changes nothing.

      Importing never turns marketing consent on, and never overwrites contact details someone has already filled in.
