Nova Lossless Audio

Raw PCM between two devices over a WebRTC data channel. No Opus, no codec.

Using this with Logic Pro (or any DAW) via BlackHole
  1. Use Chrome or Edge on the Mac. Safari can't choose an output device.
  2. Install two free BlackHole drivers from existential.audio: BlackHole 2ch and BlackHole 16ch. You need one for each direction, otherwise their audio loops straight back to them.
  3. In Audio MIDI Setup, set both BlackHole devices to 48,000 Hz, and use 48 kHz for your Logic project. Matching rates means nothing gets resampled.
  4. Still in Audio MIDI Setup, click + → Create Multi-Output Device and tick your headphones and BlackHole 16ch. You'll hear Logic, and so will they.
  5. On this page, set Input: BlackHole 16ch, Output: BlackHole 2ch and Channels: Stereo, then Connect.
  6. In Logic, go to Settings → Audio → Devices. Set Input Device: BlackHole 2ch and Output Device: Multi-Output Device.
  7. To record them: make a stereo audio track with input 1–2, arm it and hit record.
    To send to them: anything Logic plays through its main output goes to them.
  8. Watch out: if you monitor their track in Logic, it plays through the main output and they'll hear themselves delayed. Turn input monitoring off on that track. You'll still hear them on the Multi-Output Device.

Wear headphones on both ends (unless you're routing through BlackHole). Echo cancellation is deliberately off so the PCM is untouched, which means speakers will feed back into the mic.

Every frame that arrives is bit-exact (the data channel is checksummed and encrypted end to end). Frames that arrive too late to play are counted as lost or late rather than retried indefinitely, to keep latency low.
